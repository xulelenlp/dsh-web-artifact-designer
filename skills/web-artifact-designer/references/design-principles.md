# 设计原则参考

这份文档是「把 AI 生成的普通页面变成有设计感的作品」的操作手册。按需查阅，不必全读——但做设计类产出前，至少扫一遍「反模式」和「速查配方」。

## 一、反模式：一眼看穿的「AI 味」

这些是 AI 生成设计的常见通病，出现任何一条都会让作品显得廉价。**主动避开它们，就已经领先 80% 的同类输出。**

| 反模式 | 为什么廉价 | 怎么改 |
|---|---|---|
| 紫→蓝 / 靛→品红 默认渐变背景 | 被用滥到成为「AI 生成」的标签 | 用实色、低饱和底色，或从概念推导的克制渐变；渐变只做局部点缀 |
| 所有内容居中、无层级 | 没有焦点，读起来累 | 建立左对齐 + 明确的主次字号阶梯 |
| 全部用 Inter/Roboto 且字号雷同 | 没性格，像默认模板 | 标题换有辨识度的显示字体，正文才用中性字体 |
| emoji 当图标 | 尺寸/风格不可控，显得敷衍 | 内联 SVG 图标（线性/填充统一）、或用几何图形 |
| 每个卡片都一样的圆角、一样的灰边 | 无节奏，像自动生成列表 | 差异化视觉权重，重点卡片更突出 |
| 阴影乱用（又大又糊的 box-shadow） | 显脏、无光源逻辑 | 阴影要轻、要有一致方向；多数时候靠边框/留白分层即可 |
| 颜色随手挑、没有系统 | 花、冲突、无记忆点 | 用 CSS 变量定义主/辅/中性三组色 |
| `margin: 20px` 随机散布 | 节奏混乱 | 用固定间距刻度（4/8/16/24/32/48） |
| 无响应式或小屏全塌 | 交付不完整 | 关键断点检查、用 grid/flex 自适应 |

## 二、字体排印（占设计 90%）

### 层级阶梯

一份设计稿至少要有 4 个清晰层级：

1. **主标题（Display）**：最大、最重，或最有性格的字体。传达唯一焦点。
2. **副标题（Subhead）**：比主标题小 1-2 档，说明「这一块讲什么」。
3. **正文（Body）**：16-18px、舒适行高（1.6-1.75）、最大可读性。
4. **辅助/标注（Caption/Label）**：小号、全大写或加字距，用于标签、脚注、按钮。

**对比要明显**：相邻两级的字号/字重差距太小（比如 24px vs 22px）是最常见的低级错误。用 1.25-1.5 倍的比例拉开。

### 搭配原则

- **标题有性格，正文求舒适**。显示字体（Display/Slab/手写/几何）负责第一印象，正文用中性无衬线（Inter、system-ui、思源黑体等）保证长文可读。
- **一个页面 1-2 个字体族足够**。多一个字体就多一份混乱风险；想多变化用「同族的不同字重/字距」而不是再引入新字体。
- **中文注意**：中文没有「斜体」的天然做法，靠**字重 + 字距 + 字号 + 颜色**做层级；标题可用 Noto Sans SC / Source Han Sans（思源黑体）的中等字重，正文用系统栈。Web 中文字体体积巨大（几 MB），务必子集化或接受系统字体，不要为中文随意挂全量 CDN 字体。

### 细节参数

- 标题：行高 1.1-1.25，字距可略收紧（`letter-spacing: -0.01em~-0.02em`）。
- 正文：行高 1.6-1.75，段落间距用 `margin-bottom` 而非空行。
- 全大写标签（英文）：`letter-spacing: 0.08em-0.15em`，字号 11-13px。
- 大字号（>48px）默认收紧字距，否则显散。

## 三、色彩

### 建一套系统，而不是挑几个色

用 **主色 + 辅色 + 中性色** 三组，写进 CSS 变量：

```css
:root {
  --bg: #faf7f2;          /* 中性底色（可带极轻微色相） */
  --surface: #ffffff;     /* 卡片/面板 */
  --text: #1c1917;        /* 主文字 */
  --muted: #78716c;       /* 次要文字 */
  --primary: #b45309;     /* 主色：来自概念 */
  --primary-ink: #ffffff; /* 主色上的文字 */
  --accent: #0e7490;      /* 辅色：点缀、图表第二系列 */
  --border: #e7e5e4;      /* 边框 */
}
```

### 从概念取主色

- 「复古报纸」→ 米白底 + 墨黑 + 暗红。
- 「环保/自然」→ 低饱和绿 + 暖灰。
- 「科技/数据」→ 深蓝黑底 + 一个高亮青/绿。
- 「奢华」→ 深色底 + 金/铜。
- 有品牌色 → 直接用品牌色做主色，围绕它配中性色。

### 对比度（可访问性）

- 正文 vs 背景 ≥ **4.5:1**（WCAG AA）。
- 大字（≥18.66px 粗体 或 ≥24px）≥ **3:1**。
- 避免纯黑 `#000` 配纯白 `#fff` 的刺眼对比，用 `#1c1917`/`#faf7f2` 这类微调色更高级。
- 中性色不是「灰」，而是带一点点色相（暖灰/冷灰）——纯灰 `#999` 显脏。

### 60-30-10 法则（作为起点）

约 60% 中性（底+文字）、30% 主色区域（主色或它的浅/深变体）、10% 辅色（强调/点缀/图表）。不必严格计数，但它提醒你：**主色不要涂满全屏**。

## 四、布局与留白

### 网格与对齐

- 先定栅格：内容区最大宽度（如 `max-width: 1080px`）、列数（12/8/4）、栏间距。
- 元素对齐到同一条看不见的线。左对齐是默认的正确选择，居中只用于「对称海报」这类刻意场景。
- 用 `grid`/`flex` 实现，不要用一堆 `position: absolute` 硬凑（除非是刻意的不规则构图）。

### 留白是设计的一部分

- 一块内容周围的留白，通常比内容本身更「贵」。宁可松，不要挤。
- 用间距刻度：`4 / 8 / 16 / 24 / 32 / 48 / 64`。相邻区块用大间距（32-64），区块内元素用小间距（8-16）。
- 空出来的地方让它空着——留白是呼吸，不是「没填满」。

### 响应式

- 移动优先或用 `min-width` 断点：640 / 768 / 1024 / 1280。
- 用 `clamp()` 做流式字号：`font-size: clamp(2rem, 5vw, 3.5rem)`。
- 栅格在小屏退成单列，图片 `max-width: 100%`，别让横向滚动出现。

## 五、细节与完成度（拉开差距的地方）

- **边框 vs 阴影**：轻边框（1px、低对比）+ 少量留白是「干净」的关键；阴影要轻（`box-shadow` 透明度 ≤10%）、方向一致（如都从上方或都从左上）。
- **圆角统一**：一套圆角刻度（如 4/8/12/16），按钮和输入框用同一档，不要每块随机。
- **图标**：内联 SVG，统一线性或填充风格，统一描边宽度。图标库里找（Heroicons / Lucide / Feather 的路径都可内联），不要混用多套风格。
- **微动效**：hover 过渡、淡入、一个克制的入场动画能显著提升「精致感」；但动效要统一、要短（150-300ms）、要有意义，不要整页乱飞。
- **数据可视化**：图表用 SVG 或 CSS 手绘（柱状/折线/环形），颜色取自配色系统；去掉多余网格线和 3D 效果；直接标注数值比纯靠坐标轴更清晰。
- **一致性收尾**：检查所有按钮样式一致、所有间距对齐、所有颜色来自变量、所有图标风格统一。

## 六、速查配方（拿不准时直接用）

**极简瑞士风**：大量留白 + 大号无衬线标题（收紧字距）+ 黑白/单色 + 细网格线 + 左对齐。

**现代产品落地页**：中性浅底 + 一个高饱和主色做 CTA + 大标题 + 三段式（hero/features/CTA）+ 卡片轻边框。

**数据信息图**：横向/纵向栅格分区 + 大数字 + 简单柱/折线 SVG + 一个主色一个辅色 + 分区标题清晰。

**复古编辑风**：米白底 + 衬线大标题（如 Playfair/Noto Serif）+ 细线分隔 + 高对比黑红 + 装饰性数字/编号。

**暗色科技风**：深蓝黑底 + 一个霓虹强调色 + 细边框发光卡片 + 等宽字体点缀数据/代码。

## 七、一句判断

每次交付前问自己：**「如果把这个作品放进一个设计作品集，我敢署名吗？」** 不敢，就继续改。
